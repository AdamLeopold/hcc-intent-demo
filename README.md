# HCC-INTENT 工作台演示 / workbench demo

重复 TACE 节点工作台的公开演示页面（GitHub Pages）。中文版在根目录，英文版在 `en/`。

- 全部是脚本生成的虚构患者，与任何真实病例无关；不含医院数据、模型或密钥。
- 页面在浏览器里用 `mock.js` 代替服务器：数据来自预先计算的 `demo-data.json`，AI 回答是预设脚本（其中一条节点简报和一份治疗地图分析是预先录制的真实模型输出，病例同样是虚构的）。
- 在页面上填写的记录只保存在当前标签页，刷新即清空。
- 由源项目中的 `scripts/build_static_demo.py` 生成，请勿手工修改。

Public demo of the repeat-TACE node workbench (GitHub Pages). Chinese at the root, English in `en/`.

- All patients are made up by a script and unrelated to any real case; no hospital data, models or keys.
- In the browser, `mock.js` stands in for the server: data comes from the pre-computed `demo-data.json` and AI answers are preset scripts (one node brief and one treatment-map analysis are pre-recorded real model output about a made-up patient, translated from Chinese on the English page).
- Records you fill in stay in the current tab and are cleared on reload.
- Generated by `scripts/build_static_demo.py` in the source project; do not edit by hand.
