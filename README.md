# HCC-INTENT 患者治疗地图与重复 TACE 节点工作台 / treatment map and workbench

GitHub Pages 静态页面。打开时是患者治疗地图（`index.html`），另有重复 TACE 节点工作台（`workbench.html`）；中文在根目录，英文在 `en/`，页头可切换。

- 患者全部由脚本生成，与任何真实病例无关；姓名是虚构的，按脱敏样式显示（如“王*明 · 尾号已隐去”）。不含医院数据、模型或密钥。
- 浏览器里由 `mock.js` 代替服务器：数据来自预先计算的 `data.json`；AI 回答按固定模板生成，其中一条节点简报和一份治疗地图分析是保存下来的真实模型输出（病例同样是脚本生成的）。
- 页面上的编辑只保存在当前标签页，刷新即清空。
- 由源项目中的 `scripts/build_static_demo.py` 生成，请勿手工修改。

Static pages on GitHub Pages: the patient treatment map opens first (`index.html`), with the repeat-TACE node workbench in `workbench.html`; Chinese at the root, English in `en/`, switchable in the page header.

- Every patient is generated by a script and unrelated to any real case; names are invented and shown masked (e.g. “Wang *ming · ID tail hidden”). No hospital data, models or keys.
- In the browser, `mock.js` stands in for the server: data comes from the pre-computed `data.json`; AI answers follow fixed templates, except one node brief and one treatment-map analysis, which are saved real model output about a script-generated patient (translated from Chinese on the English pages).
- Edits made on the pages stay in the current tab and are cleared on reload.
- Generated by `scripts/build_static_demo.py` in the source project; do not edit by hand.
